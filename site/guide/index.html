Guide

Getting started

Manovella is a Claude Code plugin that makes product films as code: promo loops, teasers, tutorials and release films, built from your product’s own brand and interface.

What it is

A film is one HTML page whose seek(t) draws the frame at time t from scratch. Headless Chrome captures the page frame by frame, sixteen subframes each, and ffmpeg blends and encodes them. The film is a function and the video a sampling of it, so any frame can be reviewed as a still, a change costs a re-render of what changed, and a loop closes to the pixel.

You ask for a film in words, or brief it in the Studio. Claude answers with three storyboards, then stills, and renders only when you say go. Nothing renders on its own.

Manovella is Italian for the hand crank of an old film camera, the one that advances the film frame by frame.

Requirements

  • macOS on Apple Silicon, with Claude Code.
  • Node (tested with 24.3), ffmpeg (tested with 9.0.2) and Google Chrome. The renderer drives Chrome through playwright-core, installed in each film’s work folder: nothing else is downloaded. With Homebrew: brew install node ffmpeg.
  • Xcode Command Line Tools (swiftc), optional: for the Studio’s own window and the chip’s thermometer. Without them the Studio opens in a Chrome app window, and renders are held on macOS’s thermal state.
  • Voices, optional. Python 3.13 and a one-time setup (see Sound). Without them a film speaks with a macOS voice, or not at all.

Install

Manovella is a Claude Code plugin with a marketplace of its own:

claude plugin marketplace add gfazioli/manovella
claude plugin install manovella@manovella

To update by hand, run claude plugin marketplace update manovella and then claude plugin update manovella@manovella. Or declare it in ~/.claude/settings.json (merged into what is there) and Claude Code keeps the plugin current: { "extraKnownMarketplaces": { "manovella": { "source": { "source": "github", "repo": "gfazioli/manovella" }, "autoUpdate": true } } }.

The window app

The Studio opens in a small app of its own, built once per Mac (and again after a change to the window kit or to studio.json). Without it the Studio opens in a Chrome app window.

S=$(ls -d ~/.claude/plugins/cache/manovella/manovella/*/skills/site-promo-film | sort -V | tail -1)
"$S/studio/window/build.sh" "$S/studio"     # installs ~/Applications/Manovella.app

A first film

Three ways in, all inside Claude Code:

AskWhat happens
/manovella:studioThe Studio, ending in a brief that Claude answers with three storyboards.
/manovella:site-promo-filmA promo, launch, teaser, tutorial or explainer film of a product, site or app. ? is the guided mode.
/manovella:release-filmA “what’s new” film of one release, the changed surfaces rebuilt from the app’s source at the tag.

Or just ask: “a 15 s promo loop of acme.app, 16:9 and 9:16, with our music”. Claude fills what you leave out with a default, asks what it cannot guess, and waits for you at the storyboards, at the contact sheet and at the delivery. Making a film walks through each step.
